Πρότυπο Διπλωματικής
ΣΗΜΜΥ ΕΜΠ

LaTeX πρότυπο για τη διπλωματική σου, έτοιμο για Overleaf. Γράφεις ελληνικά και αγγλικά στην ίδια πρόταση, χωρίς \en{…}, και κάνει compile με XeLaTeX, LuaLaTeX ή pdfLaTeX.

Άνοιγμα στο Overleaf Λήψη ZIP Δείγμα PDF

Δημιουργεί νέο project στο Overleaf με το πρότυπο και XeLaTeX ήδη επιλεγμένο.

Η ίδια πρόταση, όπως την πληκτρολογείς, χωρίς καμία εντολή:

Αρχικό πρότυπο, pdfLaTeX Χρησιμοποιήσαμε Μαψηινε Λεαρνινγ και Πψτηον 3.12 για το προθεστ.
Αυτό το πρότυπο, XeLaTeX Χρησιμοποιήσαμε Machine Learning και Python 3.12 για το project.

Ξεκίνημα

Τρία βήματα: παίρνεις το πρότυπο, γράφεις το κείμενό σου στα αρχεία του και βγάζεις το PDF. Διάλεξε πού θα δουλεύεις:

Στο Overleaf το πιο απλό

  1. Παίρνεις το πρότυποΠάτα «Άνοιγμα στο Overleaf» στην αρχή της σελίδας. Ανοίγει νέο project με XeLaTeX ήδη επιλεγμένο.
  2. ΓράφειςΣτον editor του Overleaf, στα αρχεία του project (δες πού γράφεις τι).
  3. Βγάζεις το PDFΠάτα Recompile. Το PDF εμφανίζεται δεξιά και κατεβαίνει με το κουμπί λήψης από πάνω του.

Το δωρεάν Overleaf σταματά κάθε compile στα 10 δευτερόλεπτα· δες τι κάνεις.

Στο GitHub χωρίς όριο χρόνου

  1. Παίρνεις το πρότυποΣτο GitHub του προτύπου πάτα Use this template → Create a new repository. Διάλεξε Private για να μη φαίνεται η εργασία σου.
  2. ΓράφειςΣτο δικό σου repository άνοιξε ένα αρχείο, πάτα το μολύβι (ή το πλήκτρο . για πλήρη editor), γράψε και πάτα Commit changes.
  3. Βγάζεις το PDFΣε κάθε commit το GitHub κάνει compile μόνο του, σε περίπου 2 λεπτά (φαίνεται στο Actions). Το PDF: Releases → pdf → thesis.pdf.

Χωρίς εγκατάσταση. Στα ιδιωτικά repositories κάθε compile μετράει στα δωρεάν λεπτά του μήνα του λογαριασμού σου.

Στον υπολογιστή σου και offline

  1. Παίρνεις το πρότυποΛήψη ZIP και, μία φορά, εγκατάσταση TeX: MiKTeX ή TeX Live (Windows, Linux), MacTeX (macOS).
  2. ΓράφειςΣε όποιον editor θες, π.χ. VS Code ή Notepad++.
  3. Βγάζεις το PDFΆνοιξε τον offline compiler: python compile.py στον φάκελο του προτύπου (στα Windows και με διπλό κλικ). Ανοίγει στον browser, με κουμπί Compile, τα σφάλματα με τη γραμμή τους και το PDF δίπλα.

Offline compiler

Το compile.py υπάρχει ήδη μέσα στο ZIP. Θέλει Python 3.7 ή νεότερη, χωρίς τίποτε άλλο. Αν προτιμάς τερματικό: latexmk -xelatex main.tex.

Πού γράφεις το κείμενό σου

Το πρότυπο έχει ήδη μια εργασία-παράδειγμα. Σβήνεις το κείμενό της και γράφεις το δικό σου στα ίδια αρχεία:

ΤιΑρχείο
Τίτλος, όνομα, επιβλέπωνmain.tex, στην αρχή: \title{…}, \authorNameGR{…}, \supervisor{…} κ.λπ.
Περίληψη, ευχαριστίες, πρόλογοςfront_matter/abstract.tex, acknowledgements.tex, preface.tex
Κεφάλαιαbody_matter/intro.tex, chap2.tex … chap9.tex
Παραρτήματαback_matter/appA.tex … appE.tex
Εικόνεςφάκελος figures/
Βιβλιογραφίαreferences.bib
  • Λιγότερα ή περισσότερα κεφάλαια: σβήνεις ή προσθέτεις γραμμές \include{body_matter/…} στο τέλος του main.tex.
  • Έχεις ήδη γραμμένο κείμενο σε LaTeX; Αντιγράφεις μόνο το περιεχόμενο κάθε κεφαλαίου στο αντίστοιχο αρχείο, χωρίς \documentclass και \begin{document}. Όσα \usepackage{…} χρειάζεται μπαίνουν στο main.tex, μετά το \documentclass.

Το όριο των 10 δευτερολέπτων στο Overleaf

Όσο γράφεις, κράτα τις επιλογές plain,noindex που έχει ήδη το main.tex: το compile γίνεται πολύ πιο γρήγορο. Αν το πρώτο compile λήξει, πάτα ξανά Recompile. Για την τελική έκδοση, με τα γραφικά και το ευρετήριο, βγάλε το PDF από το GitHub ή τον υπολογιστή σου.

Overleaf χωρίς το κουμπί

  1. Κατέβασε το ZIP.
  2. Overleaf: New Project → Upload Project και διάλεξε το ZIP.
  3. Menu → Compiler: XeLaTeX και TeX Live version: η πιο πρόσφατη.

Άλλες μηχανές

latexmk -xelatex main.tex   # προτείνεται
latexmk -pdf main.tex       # pdfLaTeX
latexmk -lualatex main.tex  # LuaLaTeX

Άλλη γραμματοσειρά

Μετά το \documentclass, π.χ. CMU Serif:

\setmainfont{cmun}[Extension=.otf,
  UprightFont=*rm, BoldFont=*bx,
  ItalicFont=*ti, BoldItalicFont=*bi]
